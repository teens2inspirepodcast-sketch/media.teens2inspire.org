Teens2Inspire Media — Vercel deployment

This archive is flattened so the Next.js app files are at the ZIP/repository root.
The root directory should contain package.json, next.config.ts, src/, and public/.
For a Vercel project connected to this repository, set Root Directory to empty (repository root).
Build command: npm run build
Install command: npm install
Output directory: Next.js default

Do not commit real .env files or secrets. Configure required environment variables in Vercel Project Settings.
