# Teens2Inspire — enforced dark-theme text contrast

## Design rule
- Dark background: all text must be white, light pink or light-lilac.
- White/light background: text must be dark enough to read.
- Dark UI fields: light text and legible placeholders.
- Pink call-to-action buttons: darker rose background with white labels.
- The website media mockup/partner-logo white canvases intentionally retain dark text.

## Scope
- Changes in existing source files: `src/app/globals.css` only.
- Added this note; no Supabase, Stripe, API, authentication, storage, database, or React code changes.
- This is a style correction, not a claim that previously missing features have been implemented.

## Deployment
Replace the corresponding project's source with the contents of this package and deploy through your usual GitHub/Vercel workflow. Check on both desktop and mobile. Production build/live end-to-end verification remains required.
