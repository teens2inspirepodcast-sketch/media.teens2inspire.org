TEENS2INSPIRE MEDIA DEPLOYMENT

1. Create a NEW Vercel project from this folder/repository.
2. Project name: teens2inspire-media
3. Add domain: media.teens2inspire.com
4. Add these Production environment variables:

NEXT_PUBLIC_SUPABASE_URL
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY
NEXT_PUBLIC_SITE_URL=https://media.teens2inspire.com
SUPABASE_SECRET_KEY
R2_ACCOUNT_ID
R2_ACCESS_KEY_ID
R2_SECRET_ACCESS_KEY
R2_PRIVATE_BUCKET_NAME
R2_PUBLIC_BUCKET_NAME
R2_PUBLIC_BASE_URL=<your R2 public/custom asset domain>

5. Supabase Auth: the main signup/email-verification flow remains on teens2inspire.org. The media app only signs existing users in.
6. Cloudflare R2: use a private bucket for media files and a public bucket for thumbnails/artwork.
7. Make sure the R2 token can read/write the two buckets used by the app.
8. Deploy.
9. Test:
   - Home
   - Listen
   - Watch
   - Read
   - Resources
   - Search
   - Sign in
   - Account
   - Admin
   - Upload a real podcast/video + thumbnail from Admin
10. Do not upload stock/fake media. The app is designed to render real Supabase/R2 content only.
