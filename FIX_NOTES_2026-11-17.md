# Media app: contrast and upload validation repair

- Added a final, scoped contrast stylesheet for the dark admin and light streaming app. Inputs and light panels receive dark text; dark admin cards and pink header/hero receive light text.
- Removed misleading combined minimum/maximum size error. Nonempty media files have no arbitrary minimum; empty files cannot contain media.
- Kept the 2,000 MB media upload limit, with multipart uploads above 80 MB. Truly unlimited files are not possible; server and storage restrictions still apply.
- Cover art and captions use separate Supabase buckets with their own limits.
- Requires GitHub/Vercel deployment; multipart upload also requires the matching Supabase r2-media Edge Function.
- This is a source-level contrast repair; a visual QA pass on the live deployed pages is still needed.
